B1 · Recommended

Stash actions always visible (as in QSpace): five 24×24 icon buttons stacked permanently. Zero learning cost for affordance, matching Operate conventions.

B2
3 ⌄

Stash hover-reveal bar (surgical-instrument orthodoxy): only the pile at rest, for the best signal-to-noise; after a 150ms hover an action bar floats up at the bottom. The pile can own the full 148pt.

A1 · Recommended

Left and right split: navigation and views left (frequent, near the content), actions and layouts right (global state). The flexible space between is the window drag handle.

A2

Single dense cluster (closer to QSpace): all buttons in one run, using the least space. Cost: no grouping semantics and slightly more mis-clicks.
